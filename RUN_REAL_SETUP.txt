PART A - ACCOUNTS AND KEYS YOU MUST CREATE
------------------------------------------------------------------------------
Three external services power the app. Only #1 is mandatory to boot.

1) GOOGLE GEMINI  (REQUIRED - app will not start without it)
   Sign up / create key : https://aistudio.google.com/apikey
   Free tier            : yes (rate limited)
   Used for             : chat answers + text embeddings + document indexing
   Env variable         : GEMINI_API_KEY
   Models used          : gemini-flash-lite-latest, gemini-embedding-001

2) MEM0 CLOUD MEMORY  (OPTIONAL - enables "remembers you")
   Sign up / create key : https://app.mem0.ai/dashboard/api-keys
   Free tier            : yes (limited)
   Used for             : persistent facts across sessions
   Env variable         : MEM0_API_KEY
   Without it           : memory features are silently disabled, app still works

3) NEO4J AURADB  (OPTIONAL - enables graph RAG + graph visualisation)
   Sign up / create instance : https://console.neo4j.io
   Free tier                 : AuraDB Free
   Used for                  : property-graph index, chunk storage, graph view
   Env variables             : NEO4J_URI, NEO4J_USERNAME, NEO4J_PASSWORD
   IMPORTANT                 : NEO4J_USERNAME must be "neo4j"
                               (the code uses the username as the database
                               name, and Aura's default database is "neo4j")
   URI format                : neo4j+s://xxxxxxxx.databases.neo4j.io
   Without it                : app answers via Gemini only; graph shows mock

No other paid services are required.

PART I - KNOWN NON-BLOCKING ISSUES
------------------------------------------------------------------------------
- GET /favicon.png returns 500 in the server log. This is a Streamlit 1.58 /
  starlette static-route quirk. Cosmetic only; JS/CSS/fonts load with 200 and
  the UI renders normally.
- The VS Code "Integrated Browser" panel may show a blank dark page for
  Streamlit. A normal browser (Edge/Chrome) at http://localhost:8501 renders
  correctly. This was verified with headless Chromium.
- Gemini free tier is rate limited; heavy indexing may hit 429s. The app
  retries with exponential backoff.
- Neo4j vector similarity uses the vector.similarity.cosine function, which
  needs Neo4j 5.13+. AuraDB Free is 5.x, so this is fine.
- Mem0 API shape can change between SDK versions; mem0ai==2.0.4 is pinned.

PART J - TROUBLESHOOTING
------------------------------------------------------------------------------
Symptom: "Critical Configuration Missing" on load
  Cause : GEMINI_API_KEY missing/blank.
  Fix   : set it in .env, restart Streamlit.

Symptom: "Indexing failed: 400 ... API key not valid"
  Cause : placeholder or invalid GEMINI_API_KEY.
  Fix   : replace with a real key from https://aistudio.google.com/apikey.

Symptom: "Indexing failed: Could not extract text from PDF ... scanned"
  Cause : image-only (scanned) PDF, or a malformed PDF.
  Fix   : use a text-based PDF, or convert to TXT.

Symptom: Neo4j "Cannot resolve address your-db-id.databases.neo4j.io"
  Cause : still using the example URI.
  Fix   : paste the real URI from your Aura console.

Symptom: Mem0 "Invalid API key"
  Cause : placeholder MEM0_API_KEY.
  Fix   : paste a real key, or leave it blank to disable memory.

Symptom: Port already in use
  Fix   : .\.venv\Scripts\streamlit.exe run app.py --server.port 8502

Symptom: ModuleNotFoundError: core
  Cause : wrong working directory.
  Fix   : cd into C:\Users\inaya\Documents\INAYAT before launching.

Symptom: "No module named pypdf" during ingest
  Fix   : .\.venv\Scripts\python.exe -m pip install pypdf==6.9.2

Symptom: Stale cache after changing .env
  Fix   : fully stop Streamlit (Ctrl+C) and start it again. Env vars are read
          at startup.
